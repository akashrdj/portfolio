# Akash R Jadhav — Personal Portfolio

Welcome to my interactive developer portfolio showcasing high-performance distributed systems, industrial observability pipelines, agentic AI architectures, and federated learning research.

## 🚀 Live Demo
- **URL**: [https://akash-portfolio.vercel.app](https://akash-portfolio.vercel.app) *(or your deployed Vercel domain)*

## 🛠️ Tech Stack & Architecture
- **Core**: Semantic HTML5, Modern Vanilla CSS3, Modular JavaScript (ES6+)
- **Visuals & 3D**:
  - Interactive Ambient Particle Network Canvas
  - 3D Holographic Card Tilt physics
  - Dynamic "Role Lens" Persona Switcher
  - Animated Metric Counters
- **Icons & Fonts**: Font Awesome 6, Plus Jakarta Sans, JetBrains Mono, Syne
- **Hosting**: Vercel Global Edge CDN

## 📦 Local Development
To run this project locally:
```bash
# Using Python
python -m http.server 3000

# Or using Node / npx
npx serve .
```
Visit `http://localhost:3000`.
